# Fill Level Indicator - Power BI Custom Visual

The **Fill Level Indicator** is a custom Power BI visual designed to display the **fill level, capacity, and contents** of tanks, reservoirs, and chemical storage containers.  
It includes **dynamic wave animation** to provide a realistic and engaging visualization.

## Features
- Wave animation to indicate fill level
- Customizable capacity and fill values
- Support for different use cases such as chemical tanks, reservoirs, and liquid storage
- Easy integration into Power BI dashboards
